# cardinality_estimation_algorithms
Experimental study of Cardinality estimation Algorithms. 
Assignment for the RA subject of the Master in Innovation and Research in Informatics @ UPC

# Execution
Just run
````
$ python3 MainComparison.py
````
In the MAIN section of the script, comment or uncomment which experiments you want to run.

# Requirements

Install the random Family Hash Functions Python module:

````
$ pip install randomhash
````

Then you can execute the MainComparison.py
